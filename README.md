## 動作確認方法

Node.js / npm が利用できる任意のディレクトリに clone した後、  
以下のコマンドで必要なパッケージをインストールします。

```bash
npm install
```

その後、以下を実行してください。

```bash
npm run dev
```

ローカル環境でアプリケーションを確認できます。

詳細については、Viteの公式ドキュメントを参照してください。
