To-Do-App

2026/04/30 - 2026/05/15
新人研修の一環としてドットインストール上の「ReactでTodo管理アプリを作ろう」レッスンで
作成したTodoアプリに、計8日間の稼働日で追加機能を開発しました。
追加機能開発前のコードは public/org 下に配置しています。

--動作について--
正しい動作環境の書き方がいまいちわからないのですが、
開発時は以下の環境で動作を確認しています。

OS: windows 11 (26/05/15時点のバージョン)
Node.js: ver24.15.0 (26/04/30時点のLTS)
npm: ver11.12.1 (Node.js installerに付随)

--動作確認方法--
Node.js, npmが動作する任意のディレクトリにcloneした後、
$ npm install
で必要なパッケージをインストールします。その後
$ npm run dev
と入力することでローカル上で動作を確認できます。
動作確認についての詳細はviteのリファレンスを参照してください。

--開発スケジュール--
それぞれの追加機能に対して、設計書を作成したのちに実装に取り組みました。
設計書には、該当機能に関する
・動作イメージ
・各部品の説明
・イベント
・(一部)state定義
を含んでいます。
